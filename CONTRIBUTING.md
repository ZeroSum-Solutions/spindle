# Contributing

Thanks for helping. Before your first pull request is merged, the CLA bot asks you to sign the [Contributor License Agreement](CLA.md).

1. Open an issue first for anything bigger than a small fix.
2. Work on a branch and use conventional commits (`feat: …`, `fix: …`, `docs: …`).
3. Run `pnpm check` before you push.
4. Curriculum changes: science statements need a claim with a cited source. Write explanations in your own words; do not paste text from papers or textbooks.
5. Never include client data, secrets or proprietary gym methods.
